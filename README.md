# 📸 Responsive Photo Gallery

A clean and interactive **responsive photo gallery** built with **HTML
and CSS**.

The gallery uses a modern card layout where photos start in grayscale
and smoothly expand into a larger view when the user hovers over them.

## ✨ Features

-   🎨 Modern dark UI
-   🖼️ Responsive photo gallery
-   🖱️ Smooth hover-to-expand animation
-   🌑 Grayscale-to-color image effect
-   📱 Mobile-friendly layout
-   ⚡ Lightweight and fast
-   🔧 Built with pure HTML & CSS
-   🚀 Ready for GitHub Pages

## 🛠️ Technologies Used

-   **HTML5** --- page structure
-   **CSS3** --- layout, animations and responsive design

No JavaScript or external framework is required.

## 🚀 Run Locally

1.  Clone the repository:

``` bash
git clone https://github.com/narutoxsuraj/responsive-photo-gallery.git
```

2.  Open the project folder.
3.  Open `index.html` in your browser.

For the best development experience, open the folder in **VS Code** and
use the **Live Server** extension.

## 🌐 Deploy with GitHub Pages

This project is compatible with GitHub Pages.

Go to:

**Repository → Settings → Pages**

Then select:

-   **Source:** Deploy from a branch
-   **Branch:** `main`
-   **Folder:** `/ (root)`

Save the settings and GitHub will generate the live website URL.

## 🎯 How It Works

Each image is placed inside a flexible gallery card.

When the user moves the cursor over a card:

-   The selected card expands.
-   The image changes from grayscale to full color.
-   A smooth transition makes the interaction feel natural.

On smaller screens, the layout automatically adapts for mobile devices.
